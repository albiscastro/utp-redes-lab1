 Laboratorio 1: Fundamentos de Redes

 Propósito
Documentar el laboratorio inicial de redes de la asignatura de la Licenciatura en Ciberseguridad (UTP - FISC): conceptos del modelo OSI/TCP-IP y captura básica de tráfico.

 Topología
- 2 PCs conectadas a un switch
- 1 router conectado al switch
- Herramienta: Cisco Packet Tracer



Herramientas
- Cisco Packet Tracer
- Wireshark
- Git / GitHub


Resultados
- Conectividad exitosa entre los dispositivos.
- Identificación de las capas del modelo OSI en los paquetes capturados.
